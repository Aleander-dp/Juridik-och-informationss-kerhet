# Juridik-och-informationss-kerhet
Projekt i kursen Juridik och informationssäkerhet

## filer
Diskussions anteckningar från min grupp, Presentation i två olika format (pptx, pdf)

## Syfte
Syftet med detta projet var att bedöma företaget PillMedTech informationssäkerhetsmognad. Detta innebär att vi använde oss av MSB:s mognadsdialog för att identifiera brister för att vi senare ska ta fram konkreta förbättringsåtgärder för att höja företagets säkerhetsmognad. Vi använde oss av ISO 27000 standarderna, samt NIS2 lagstiftningen vid bedömning av företaget.

## Bedömningsområden
- Riskhantering
- Incidenthantering
- Informationsklassning
- Upphandling
- Kompetens
- Uppföljning
